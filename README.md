# Motorcycle routes app

A application that shows routes from different motorcycle riders that they have posted. You are able to like and comment on a post or even post your own route.

the post contains the user with their profile picture, the time of when it was posted, a title of the route, a description of the route, a image of the route itself (this image is a random line graph from point A to B and not realistic), the distance of the route, the duraction, the points of interest, likes and comments on the post.
